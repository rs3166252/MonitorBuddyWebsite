# Monitor Buddy Website

Public website for **Monitor Buddy**, a Windows utility for switching compatible monitor inputs with configurable keyboard shortcuts using DDC/CI.

## 🌐 Production

**Website:** https://monitorbuddy.cstrikerdj.in

**Application releases:** https://github.com/rs3166252/MonitorBuddy/releases

## 🎯 What this website explains

The site presents Monitor Buddy as a simple, practical solution for people sharing one monitor between a PC, PS5, or other devices.

The project started from a manual monitor-control approach we discovered through a YouTube video. We then turned that starting point into a dedicated application with setup assistance, monitor discovery, profiles, configurable shortcuts, and a portable release workflow.

The goal is simple:

> **Take a problem that required several manual steps and turn it into a few clicks.**

## ⚡ From manual setup to Monitor Buddy

The original approach that inspired us was useful for showing that monitor functions could be controlled through commands and keyboard shortcuts. But using that kind of approach as a day-to-day solution can still involve finding tools, downloading dependencies, configuring commands, mapping inputs, and maintaining the setup yourself.

Monitor Buddy packages that workflow into one application:

**Download → run setup → detect/configure → press your shortcut.**

The video gave us the direction. Monitor Buddy is what we built from it.

## 📦 Repository structure
