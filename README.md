# Monitor Buddy Website

Public website for **Monitor Buddy**, a Windows utility for switching compatible monitor inputs with configurable keyboard shortcuts using DDC/CI.

## Production domain

https://monitorbuddy.cstrikerdj.in

## Deployment

This repository contains the public website only. The application implementation is maintained separately from this website repository.

The download links point to the public Monitor Buddy release repository:

https://github.com/rs3166252/MonitorBuddy/releases

## Local preview

Open `index.html` in a browser, or serve the repository directory with any static HTTP server.
