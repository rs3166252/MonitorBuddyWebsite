COMPATIBILITY

DDC/CI is the bridge.

Monitor Buddy controls input switching through DDC/CI. Compatibility depends on your monitor firmware, connection path, GPU/driver behavior, and which controls your display exposes.

Before you try it
  • Windows PC
  • External monitor with DDC/CI support
  • Input switching exposed through DDC/CI
If automatic setup cannot identify the correct control, Monitor Buddy provides a manual selection fallback.
