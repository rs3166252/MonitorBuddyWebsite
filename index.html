COMPATIBILITY

DDC/CI is required.

Monitor Buddy controls input switching through DDC/CI. Compatibility depends on the monitor firmware, connection path, GPU/driver behavior, and which controls the display exposes.

Before installing
  • Windows PC
  • External monitor with DDC/CI support
  • Input switching exposed through DDC/CI
If automatic setup cannot identify the correct control, the setup flow provides a manual selection fallback.

THE STORY BEHIND MONITOR BUDDY

It started with a problem.
Then we decided to build the fix.

Built because we needed it. Shared because someone else might need it too.

01

THE PROBLEM

PC. PS5. One monitor.

Monitor Buddy started with a problem we were actually struggling with: switching between a PC, PS5, and other devices on one monitor without constantly reaching for the monitor controls.

We wanted a software solution. Our monitor did not provide the feature we needed, and we did not want to buy expensive hardware just to make input switching easier.

02

THE STARTING POINT

Then we found a few seconds of a video.

During that search we found the YouTube video “Tech Tip: Switch Monitor Input with a Keyboard Shortcut.” It introduced us to ControlMyMonitor, DDC/CI commands, and the idea of using keyboard shortcuts to control monitor functions from Windows.

“What if we took those things to the next level?”
03

THE BUILD

From experiments to a proper application.

The first versions were experiments. We moved between PowerShell, Python, and C#, testing different ways to communicate with the monitor and turn the idea into something usable.

One of the early script-based versions worked, but it was not the release experience we wanted. Some security tools also flagged that early approach. That taught us an important lesson: making the feature work was only part of the job.

PowerShell→Python→C#→Monitor Buddy

We kept rebuilding, testing, investigating, fixing, and testing again until Monitor Buddy became a proper application rather than a collection of scripts and experiments.

04

THE RELEASE

A portable app we were comfortable putting in public.

The v1.1.0 Actual App is the build we finally wanted to share: portable, simple to run, designed around monitor identification and DDC/CI control, with Windows startup support and a straightforward user experience.

No traditional installer is required. Extract the release ZIP, run the application, and use it.

We also checked the final public release with VirusTotal. The release ZIP received 0 / 64 detections at the time of analysis.

View VirusTotal scan results
05

WHY SHARE IT?

Why keep it just for ourselves?

Other people have one-screen setups, PCs and consoles, and hardware they cannot or do not want to replace.

So we decided to make Monitor Buddy free and publicly available, with optional community support in the future if people want to help development continue.

06

THE REAL DEVELOPMENT PROCESS

Build. Test. Break. Fix. Repeat. 😂

The development process was not magic. It was build → test → break → investigate → fix → test again.

“And yes, there was an AI sitting next to us confidently suggesting things that sometimes broke the exact thing we had just fixed.” 😂

🙏 THANK YOU TO CONTROLMYMONITOR

A technical foundation that made the experiment possible.

Monitor Buddy would not have been possible without ControlMyMonitor (CMM) and the work behind it. CMM gave us a practical way to experiment with monitor settings and DDC/CI from Windows instead of having to build that entire foundation ourselves.

We genuinely respect the amount of engineering and experimentation behind a tool like CMM, especially because it is made available as freeware.

Monitor Buddy uses the CMM executable as part of its current implementation. We reviewed the official CMM distribution terms and chose to keep Monitor Buddy free rather than charge for a product that redistributes the freeware component.

If someone can put that much work into making a powerful tool available for free, why shouldn't we do the same with what we built on top of it?
