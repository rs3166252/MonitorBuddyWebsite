WHY MONITOR BUDDY?

Made for the one-screen setup.

Perfect when one monitor is shared between a PC and a console, or between several devices. Instead of opening the monitor's physical menu every time, use a keyboard shortcut.

⚡ Fast switchingConfigurable F1–F9 shortcut combinations.
🖥️ Monitor profilesSave input mappings for connected monitors.
🔎 Input scanningDiscover available DDC/CI input values.
📦 Simple releaseExtract, run setup, and start Monitor Buddy.

COMPATIBILITY

DDC/CI is required.

Monitor Buddy controls input switching through DDC/CI. Compatibility depends on the monitor firmware, connection path, GPU/driver behavior, and which controls the display exposes.

Before installing
  • Windows PC
  • External monitor with DDC/CI support
  • Input switching exposed through DDC/CI
If automatic setup cannot identify the correct control, the setup flow provides a manual selection fallback.
