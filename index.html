THE SIMPLE PROBLEM

Stop pressing monitor buttons.

If your PC and console share one screen, changing inputs can mean opening the monitor menu every time. Monitor Buddy turns that routine into a shortcut.

FEATURES

Built for a clean setup.

⚡ Keyboard shortcuts

Map inputs to configurable F1–F9 combinations for quick switching.

🖥️ Monitor profiles

Keep input mappings for your connected monitors and choose the active profile.

🔎 Input scanning

Scan the monitor for available input controls instead of relying on one hard-coded layout.

🤖 System tray

Run quietly in the tray and bring up settings whenever you need them.

📦 Portable

Extract the release, complete setup once, and use the application without a traditional installer.

🛠️ Easy setup

Automatic dependency setup is provided, with a manual selection fallback when needed.

COMPATIBILITY

DDC/CI is the key.

Monitor Buddy is designed for compatible external monitors that expose input switching through DDC/CI. Actual compatibility depends on the monitor firmware, connection path, GPU/driver behavior, and the controls exposed by the display.

Before you download

Check that your monitor supports DDC/CI and that its input source can be controlled through the display connection.
